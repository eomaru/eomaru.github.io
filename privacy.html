maru bot 개인정보처리방침

시행일: 2026년 11월 26일

누가 쓰는 앱인가

maru bot은 앱을 만든 사람 한 명이 자기 계정으로만 쓰는 개인용 비서입니다. 다른 사용자를 받지 않습니다.

어떤 구글 데이터에 접근하나

  • 구글 캘린더 일정 보기와 수정 (calendar.events)
  • Gmail 메일 읽기 (gmail.readonly)
  • Gmail로 메일 보내기 (gmail.send). 사용자가 텔레그램에서 승인 버튼을 누른 답장만 보냅니다.

메일을 지우거나 라벨을 바꾸는 권한은 받지 않습니다.

데이터를 어떻게 쓰고 어디에 두나

  • 일정과 메일은 사용자 본인에게 할 일 정리, 일정 알림, 메일 요약을 보여주는 데만 씁니다.
  • 가져온 데이터와 로그인 토큰은 사용자 본인의 맥미니에만 저장합니다. 앱 개발자 서버나 다른 곳으로 옮기지 않습니다.
  • 요약과 분류를 위해 필요한 내용은 Anthropic의 Claude API로 보내 처리합니다. 그 밖의 제3자에게 팔거나 넘기지 않습니다.
  • 구글 사용자 데이터를 광고에 쓰거나, 사람이 따로 열람하거나, AI 모델 학습에 쓰지 않습니다.

Google API 서비스 사용자 데이터 정책 준수

maru bot이 Google API로 받은 정보를 사용하고 다른 앱으로 전송하는 것은 제한적 사용 요구사항을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

삭제와 연결 끊기

구글 계정 설정의 서드파티 앱 연결에서 언제든 접근 권한을 취소할 수 있습니다. 맥미니에 저장된 데이터는 사용자가 직접 지울 수 있습니다.
